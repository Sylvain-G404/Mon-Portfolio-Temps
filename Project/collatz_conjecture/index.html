Formule de la Conjecture de Collatz

$$ f(n) = \begin{cases} n / 2 & \text{si } n \text{ est pair} \\ 3n + 1 & \text{si } n \text{ est impair} \end{cases} $$

La conjecture de Collatz, également connue sous le nom de problème 3n + 1, est une conjecture mathématique qui concerne les séquences de nombres entiers. Elle stipule que, pour tout nombre entier positif n, la séquence définie par les règles suivantes finira toujours par atteindre le nombre 1 :

  • Si n est pair, divisez-le par 2.
  • Si n est impair, multipliez-le par 3 et ajoutez 1.

Par exemple, si vous commencez avec le nombre 6, la séquence serait :

  • 6 → 3 → 10 → 5 → 16 → 8 → 4 → 2 → 1.
Malgré des efforts considérables de la part des mathématiciens, la conjecture de Collatz reste non prouvée à ce jour.
