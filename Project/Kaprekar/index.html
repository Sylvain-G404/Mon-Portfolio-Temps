Algorithme de Kaprekar

Exemple : Pour un nombre à 4 chiffres (1423)
  1. On trie les chiffres dans l'ordre décroissant :
    4->3->2->1
  2. On trie les chiffres dans l'ordre croissant :
    1->2->3->4
  3. On soustrait le plus petit du plus grand :
    4321 - 1234 = 3087
  4. On répète jusqu’à obtenir 6174
